# Gruppkontrakt

## Tillgänglighet

- Vardagar 9-16 utgår vi från att folk är tillgängliga om de inte sagt till.  
  - På kvällar och helger kan man inte förvänta sig att folk svarar. Helt OK att skicka frågor men inte att förvänta sig svar.  
  - Under tillgänglig tid förväntas man svara på meddelanden inom tre timmar men senast samma dag.  
- Jonathan förväntas inte vara tillgänglig på tisdagar då han jobbar då.

## Kommunikation

- Kommunikation sker i huvudsak via Discord på egen server. Vi sätter upp kanaler för olika syften.  
  - Enskilda frågor kan också tas på Discord via PM eller samtal.  
- Vi sätter upp en Kanban också och ska undersöka alternativ för detta (GitHub Projects?).  
- Vi för enkla protokoll på standups och andra möten som frånvarande personer kan hänvisa till i efterhand.

## Närvaro och frånvaro

- Frånvaro meddelas via Discord så snart man känner till det men som minst innan möten/standups.  
- Vid missade mindre möten (standups) kan man lägga en snabb rapport i lämplig kanal på Discord. Man behöver även titta på protokoll från missade möten så man vet vad som hänt.

## Arbetsfördelning

- I huvudsak fördelar vi via Kanban där man tar på sig uppgifter som behöver göras.  
  - Som princip ska alla ha minst en uppgift per sprint, men exakta antal behöver anpassas till hur stora uppgifterna är.  
- Vi diskuterar på möten om någon har en preferens för vissa uppgifter och om vissa uppgifter behöver göras innan andra.  
- Kör man fast hör man av sig och frågar om någon kan hjälpa till. Ju tidigare desto bättre. Finns det andra saker att göra kan man ge sig på dem så länge, men man bör se till att man inte sitter med tio påbörjade ärenden som inte blir klara.

## Beslut

- För större frågor strävar vi efter enighet men kör på majoritetsbeslut om inte detta går. För mindre beslut så kan var och en bestämma över sina egna delar så länge det inte krockar med andras och det kommuniceras ut.  
- Ändringar i databas- och modellering behöver beslutas gemensamt.  
- Som sista instans pratar vi med projektägaren (Nils).

## Konflikter och eskalering

Bestäm en trappa för vad som händer om någon inte följer kontraktet, till exempel:

1. Ta upp det direkt med personen.  
2. Ta upp det på retrospektiven.  
3. Ta upp det med läraren.
